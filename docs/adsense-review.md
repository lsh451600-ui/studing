# AdSense 재검토용 수정 기록 (2026-10-11)

관리 화면의 구체적인 반려 사유는 아직 전달받지 못했으므로 반려 원인을 확정하지 않습니다. Google 공식 안내의 고유 콘텐츠·탐색·크롤러 접근 항목을 기준으로 실제 사이트에서 개선할 수 있는 부분을 수정했습니다. 승인 자체는 Google 심사이며 코드 변경만으로 보장할 수 없습니다.

- 홈에 자체 계산 사례와 공개 가이드로 연결되는 질문별 탐색을 추가했습니다. 기존 소개·실무가이드 위치는 유지합니다.
- 준비량·폐기 비용 가이드는 계산기, 표준 단위 설명, 품절과 폐기의 비교, 인쇄 기록지, 출처와 적용 한계를 포함합니다. 가상 매장과 AI 보조 작성임을 표시하고 실제 취재나 전문가 검토를 주장하지 않습니다.
- 외부 뉴스는 제목·출처·발행일·원문 링크로 제공하며 기사 본문·사진을 복제하지 않습니다. 브라우저·정적 렌더러·API·수집기·자동 갱신을 동일하게 변경했습니다. 기존 사진 파일은 참조하지 않으며 새 사진을 수집·업로드하지 않습니다.
- 공개 가이드는 로그인 없이 접근하고, 회원 전용 페이지의 권한은 유지합니다. 광고 로더는 홈·공개 기사에만 있고 회원/정책/오류 화면에 없습니다. ads.txt의 게시자 ID와 head의 계정 ID는 일치합니다.
- 사이트맵과 본문 RSS에 새 가이드를 추가하고 개인정보 안내를 현재 저장·외부 서비스 사용 방식에 맞췄습니다.

배포 후 관리자가 AdSense의 **사이트 → dining.win → 검토 요청**을 진행해야 합니다. 이 연결에는 AdSense 관리 권한이 없어 재검토 제출이나 반려 사유 조회를 직접 수행할 수 없습니다. 등록 주소가 dining.win인지, 계정에 남은 설정 과제가 있는지도 관리 화면에서 확인하세요. 특정 게시물 수·글자 수·대기 일수를 승인 조건처럼 제시하지 않습니다.
