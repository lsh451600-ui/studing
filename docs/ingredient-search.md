# 식재료 사진으로 레시피 추천

레시피 페이지에서 특별회원 또는 운영자가 기존 열람 비밀번호로 입장하면 사용할 수 있습니다.

## 비용과 사진 처리

- 유료 AI API, API 키, 과금 계정, 새 저장소를 사용하지 않습니다.
- 사진은 브라우저에서 최대 768px로 축소한 뒤 Web Worker에서 분석하며, 서버나 외부 추론 서비스로 전송하지 않습니다.
- Transformers.js 3.8.1과 공개 CLIP 모델을 jsDelivr / Hugging Face에서 내려받습니다. 사용자의 기기에서 WASM으로 실행합니다. 처음 실행에는 큰 모델 다운로드가 필요하고, 이후에는 브라우저 캐시를 사용할 수 있습니다. 네트워크 데이터 사용은 별개입니다.
- 사진 자체는 저장하지 않습니다. 추천 API에는 사진에서 인식한 재료 이름만 GET으로 전달합니다. 기존 사이트의 데이터베이스·호스팅 이용 한도는 그대로 적용됩니다.
- 기존 유료 API가 있을 수 있는 다른 기능의 설정이나 자동화는 변경하지 않습니다.

공개 구현: [Transformers.js](https://huggingface.co/docs/transformers.js/pipelines), [CLIP ONNX 모델](https://huggingface.co/Xenova/clip-vit-base-patch32) (MIT).

## 사진 인식

흔한 식재료의 영문 시각 라벨과 사진 전체 및 겹치는 4개 영역을 비교해 한국어 재료 후보를 보여줍니다. 정확한 물체 검출·분량 측정·식품 안전 판정 기능은 아닙니다. 여러 재료가 겹친 사진, 조리한 음식, 포장된 식품, 비슷한 채소는 오인식하거나 누락될 수 있습니다. 사진을 선택하면 재료 분석과 상위 3개 레시피 검색이 자동으로 이어집니다. 인식한 재료는 읽기 전용으로 표시하며 입력·확인 단계는 없습니다. 인식 실패 시 다른 사진이나 브라우저로 다시 시도합니다. 초기화·로그아웃 시 사진 미리보기와 결과를 비웁니다.

## 추천 기준

1. 레시피에 별도로 저장한 `ingredients` 목록을 우선 사용합니다.
2. 기존 레시피는 본문의 `재료` 구역을 우선 읽고, 해당 구역이 없으면 본문의 등록된 재료 키워드로 추정합니다. 추정 기준임을 결과에 표시합니다. 이미지나 PDF 안에만 있는 재료는 읽지 않습니다.
3. 계란→달걀, 쪽파→대파처럼 정의한 동의어를 정규화하고 중복을 제거합니다.
4. **재료 일치도 = 일치 재료 개수 / 레시피 재료 개수 × 100**. 수량, 필수·선택 구분, 식단·알레르기 조건은 점수에 포함하지 않습니다.
5. 일치도 내림차순, 일치 개수 내림차순, 부족한 재료 개수 오름차순, 글 ID 내림차순으로 정렬합니다. 비율은 반올림 전 값으로 비교합니다.
6. 페이지에 보이는 글만이 아니라 모든 등록 레시피를 100개 단위로 읽어 상위 3개를 계산합니다. 재료가 하나도 맞지 않는 글은 제외하고, 일치하는 글이 부족하면 1~2개 또는 결과 없음으로 표시합니다.

작성·수정의 재료 입력란에 쉼표로 구분하여 최대 50개(각 40자) 등록합니다. 기존 글은 수정하지 않아도 본문 키워드로 검색되지만, 정확한 추천을 위해 별도 재료 목록을 보완할 수 있습니다. 기존 클라이언트가 재료 필드 없이 수정해도 저장된 재료를 보존합니다.

## 검증

- `node --test tests/ingredient-search.test.js tests/recipes.test.js tests/private.test.js tests/community.test.js`
- `NODE_PATH=/tmp/login-browser-check/node_modules node tests/ingredient-search-ui.cjs`
- `NODE_PATH=/tmp/login-browser-check/node_modules node tests/recipe-board-ui.cjs`

UI 자동 검사는 모델 실행만 대체하여 사진 선택 후 자동 검색, 3개 추천, 인식 실패·결과 없음·검색 오류, 잠금 시 정보 제거, 모바일/PC의 밝고 어두운 모드를 확인합니다. 실제 공개 모델은 별도 브라우저 실행으로 검증합니다. 외부 이미지 분석 API는 사용하지 않습니다.
